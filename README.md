# 如是观

> 应作如是观。

一个自我纠正思维的练习场。不打卡，不记分，只看见。

---

## 为什么做这个

大多数"思维纠正"工具做的是同一件事：给你一套正确认知，让你照着改。但那只是换了一套更精致的执著——从执著"我不行"换成执著"我应该积极"。

《金刚经》走的是另一条路：它不定义般若是什么，只是不断拆掉你以为是的东西——

> 所谓佛法者，即非佛法，是名佛法。

所以这个应用不判对错。它只做两件事：**照见**，然后**放下**。

## 两个练习

### 勘

从生活里抽一个真实的情境——插队、被抢功、孩子考砸、体检异常——让你选一个最像自己的反应。

选完之后，它不告诉你选对选错，而是把**每个选项背后的相**一个一个照出来：这个反应在维护什么？那个"我"在哪里？

包括"我选了最清醒的那个"这个念头本身，也是相。

**勘的结果不做统计，也不排名。** 练习记录只用来做两件事：决定下一题出什么，以及在你再次遇到同一题时，告诉你上次选了哪个。练完一轮自动进入下一轮——轮次是圈数，不是成绩。

### 观

把当下的一次反应，拆成四步：

| 步 | 问 |
|---|---|
| 事 | 发生了什么？只写事实。 |
| 念 | 心里升起的第一句话是什么？ |
| 我 | 那个被碰到的"我"，在哪里？ |
| 观 | 如果无所住，此刻能做什么？ |

最后收成一句：所谓〔　〕，即非〔　〕，是名〔　〕。

"观"可以存下来，也可以导出为 Markdown。但"记"不是账本——它只是把看见过的，留个影子。

## 三条约束

1. **不打卡、不记分、不排名。** 练习一旦长出账本，"我在修行"这个相就立起来了。
2. **没有服务器。** 所有文字只存在这台设备的 `localStorage` 里，不发往任何地方。
3. **没有正确答案。** 只有看见，和没看见。

## 本地运行

题库是外部 JSON，浏览器在 `file://` 下会拦截读取，所以需要一个本地服务器：

```bash
npm run dev
# → http://localhost:4173
```

零依赖，不需要 `npm install`。

校验题库：

```bash
npm run validate
```

## 维护题库

题库在 [`data/questions.json`](data/questions.json)：

```json
{
  "version": 1,
  "updated": "2026-11-05",
  "questions": [
    {
      "id": "queue",
      "scene": "便利店排队，一个人径直插到你前面。",
      "prompt": "你此刻——",
      "options": [
        { "text": "选项文字", "note": "这个反应在维护什么相" }
      ],
      "coda": "最后那一问"
    }
  ]
}
```

写新题时守住一条：**`note` 是显影，不是判分。** 描述这个反应的结构，不给它打分，也不要留一个"圣人选项"。如果某个选项看起来像标准答案，就在它的 `note` 里把那个坑也指出来。

`npm run validate` 会检查字段完整性、id 唯一性，并提醒过短或过长的内容。

## 部署到 GitHub Pages

纯静态，无需构建：

1. 推送到 GitHub
2. Settings → Pages → Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`
4. 等待一两分钟

## 项目结构

```
.
├── index.html          页面骨架
├── styles.css          宣纸、墨、朱砂
├── app.js              视图与交互（原生 JS，无框架）
├── db.js               IndexedDB 封装（entries / practice）
├── data/
│   └── questions.json  题库
├── scripts/
│   ├── serve.mjs       本地静态服务器
│   └── validate.mjs    题库校验
└── package.json
```

## 数据与隐私

- 「观」的记录存在 IndexedDB 的 `entries` store，「勘」的练习记录存在 `practice` store（库名 `rushi`）。
- 练习记录只用于选题和显示上次选择，不做正确率、不做连续天数、不做排名。
- 没有分析、没有埋点、没有网络请求（除了加载题库本身）。
- 换设备不会同步。导出 Markdown 是唯一的搬运方式。
- 旧版 localStorage 数据会在首次打开时自动迁移。
